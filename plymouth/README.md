# Plymouth

Tema de boot da instalação nova.

> **Estado:** esta pasta fica vazia até a fase F9.

## O que entra

O tema Wintermute do Plymouth, que hoje vive em um projeto separado nesta máquina, com o script de instalação e as instruções para ativá-lo.

## O que a fase F9 confere

- O tema funciona com o gerenciador de boot da instalação nova.
- A instalação do tema pode ser repetida sem estragar nada e sabe ser desfeita.
- A transição entre o boot e a tela de login fica coerente com o visual da tela de login definida na fase F7.
